## 关键知识点速查

### 双闭环设计（第1章核心）

- 电流环：按典型 I 型系统设计，电流调节器 ACR 为 PI 型
- 速度环：按典型 II 型系统设计，速度调节器 ASR 为 PI 型
- 工程整定：先整定内环（电流环），再整定外环（速度环）
- 关键参数：电气时间常数 $T_l$、机械时间常数 $T_m$、电流反馈系数 $\beta$、速度反馈系数 $\alpha$

### 制动方式（第1章第7节）

- 回馈制动：电机作为发电机，能量回馈电源，效率高但需要处理母线过压
- 能耗制动：通过制动电阻消耗动能，简单可靠但能量浪费
- 反接制动：电源反接，制动力矩大但冲击电流大

### 丝杠折算公式

- 线速度→转速：$n = v \times 60 / L$（L 为导程，mm）
- 线力→转矩：$T = F \cdot L / (2\pi\eta)$
- 转动惯量：$J_L = m(L/2\pi)^2$
