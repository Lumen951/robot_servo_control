# 升降执行机构伺服驱动系统 — 核心概念解析

> 本文档记录了在理解 main_params.m 输出结果过程中，对每个专业名词的逐步讨论。
> 目标：把每个参数从"陌生的数字"变成"有画面感的理解"。

---

## 一、系统整体图景

你在设计的东西：一个仓储机器人身上的"小电梯"。

- 机器人底下有轮子能跑
- 身上有一个升降平台，货箱放在上面
- 平台上升 → 把货箱送到货架上
- 平台下降 → 把货箱取下来

驱动方式：**电机转动 → 丝杠把旋转变成直线运动 → 平台上下移动**

你要设计的就是这套驱动系统：选什么电机、怎么控制它、能不能满足速度和精度要求。

---

## 二、速度参数

### 低速对接速度：84 mm/s

平台接近目标高度时的慢速移动，用于精确对准货架。每秒走 8.4 厘米，大概一个手掌的宽度。

来源：80 + AB(04) = 84，由学号决定。

### 快速升降速度：296 mm/s

正常搬运时的快速升降。每秒走 29.6 厘米，大概一个小臂的长度。

来源：220 + CD(76) = 296，由学号决定。

### 调速范围 D = 3.52

最快速度 ÷ 最慢速度 = 296 / 84 ≈ 3.52。

含义：电机不能只跑一个固定速度，必须能在 1 倍速到 3.5 倍速之间灵活切换。类比汽车需要多个档位。3.5 倍不算大，属于比较容易实现的范围。

---

## 三、丝杠与导程

### 丝杠（Ball Screw）

一根带螺旋槽的金属杆。电机带动丝杠旋转，螺母沿着螺旋槽做直线运动，从而带动平台上下移动。

本质：**把旋转运动转换成直线运动的机械装置**。

类比：螺丝钉。你转动螺丝刀（旋转），螺丝往木头里钻（直线）。丝杠就是工业版的螺丝钉。

### 导程（Lead）：10 mm

丝杠转一圈，平台移动的距离。导程 10mm = 电机转一圈，平台上升/下降 1 厘米。

导程是一个关键的设计选择：
- 导程大 → 同样转速下平台移动更快，但电机需要的扭力更大
- 导程小 → 平台移动慢但省力，类似自行车的低档位

10mm 是一个平衡选择。

### 滚珠丝杠 vs 普通丝杠

普通丝杠：螺母和丝杠直接摩擦接触，效率低（~40%），但摩擦大所以能"自锁"（断电后平台不会掉下来）。

滚珠丝杠：螺母和丝杠之间有钢珠滚动，效率高（~90%），但摩擦小所以**不能自锁**（断电后平台会因为重力掉下来）。

本项目选了滚珠丝杠（效率 0.90），所以必须额外设计"到位保持"方案（电气保持或机械抱闸）。

### 转速折算

丝杠导程把线速度和电机转速联系起来：

```
电机转速 = 线速度 × 60 ÷ 导程
```

- 低速：504 rpm = 84 mm/s × 60 ÷ 10 mm（电机每分钟转 504 圈）
- 高速：1776 rpm = 296 mm/s × 60 ÷ 10 mm（电机每分钟转 1776 圈）

rpm = revolutions per minute，每分钟转数。

## 四、负载力分析

### 负载力是什么

**负载力 = 电机需要克服的力的总和**。

就像你搬东西上楼：
- 物体的重量在向下拉（重力）
- 你的脚和地面有摩擦（摩擦力）
- 如果你加速跑，还要克服惯性

电机驱动升降平台时遇到的力也是这几类。设计电机前必须先算清楚电机要对抗多大的力。

### 两个核心力

**1. 重力**
```
F_gravity = 质量 × 9.81
```
- 方向：永远向下
- 平台自重 1.5 kg → 14.7 N
- 货物 8 kg → 78.5 N
- 平台+满载 9.5 kg → 93.2 N

9.81 是重力加速度 g，地球上的常数。

**2. 摩擦力 60 N（题目给定）**

包含导轨摩擦、丝杠螺母摩擦、其他机械连接处的摩擦。

**关键特性：永远反对运动方向**
- 平台上升 → 摩擦力向下（阻碍上升）
- 平台下降 → 摩擦力向上（阻碍下降）
- 平台静止 → 摩擦力为零（或抵消外力保持不动）

### 四种工况

约定：上升方向为正。F > 0 表示电机向上发力，F < 0 表示电机向下发力。

#### 工况 1：空载上升 74.72 N
场景：机器人卸完货，空平台返回接下一批。

```
电机向上拉 ← 重力 14.7N 向下 ← 摩擦力 60N 向下
合计：74.7 N
```

摩擦力占大头（60 比 14.7），说明平台自身很轻，主要在对抗摩擦。

#### 工况 2：满载上升 153.19 N（最费劲，额定工况）
场景：平台载 8kg 货物上送货架。

```
电机向上拉 ← 重力 93.2N 向下 ← 摩擦力 60N 向下
合计：153.2 N
```

这是所有工况中电机最费劲的情况，**电机选型必须按这个算**。

#### 工况 3：满载下放 33.20 N（制动工况）
场景：平台载 8kg 货物往下降。

```
重力 93.2N 向下 → 平台想加速下降
摩擦力 60N 向上 → 阻止下降
```

**重力 93.2 > 摩擦力 60**，净力 33.2 N 向下。

意思是：**电机如果什么都不做，平台会自己加速往下掉**。电机的任务不是"出力下降"，而是"让它慢一点下降" — 电机此刻是一个"刹车"。这就是"制动工况"名字的来历。

**制动带来一个重要后果**：电机被负载反向拖着转时，实际上变成了一个小发电机，会产生电能。这部分电能要么：
- **回馈制动**：流回电池（节能，需要额外电路处理母线过压）
- **能耗制动**：流进电阻变成热（简单，但浪费）

课程要求的"回馈制动 vs 能耗制动"分析就是在讨论这个。

#### 工况 4：空载下放 -45.28 N
场景：空平台下降。

```
重力 14.7N 向下
摩擦力 60N 向上 → 反对下降
```

**摩擦力 60 > 重力 14.7**，净力 45.3 N 向上。

意思是：**电机不发力，平台会被摩擦卡住不动**。电机必须主动往下拉平台。负号表示方向反了 — 不是向上拉而是向下推。

### 工程案例对照

**电梯**：和本项目最相似。
- 上升：电机拉钢索 = 工况 1/2
- 下降（带乘客）：变种的工况 3
- 高档电梯（日立/三菱）下降时电机变发电机，把电能回收到楼宇电网 — 这就是回馈制动的实际应用

**电动车下长坡**：松油门时电机变发电机，动能→电能→电池。你这个升降机构的满载下放工况，和电动车下山物理原理完全一样。

**港口集装箱起重机**：吊下集装箱时也是制动工况，现代港口用能量回馈把势能存起来给下次吊举用。

**电梯配重块**：设计师会让配重 = 空轿厢 + 半载乘客，让电机无论上升下降、空载满载都工作在相近负担水平，减小峰值功率需求。**本项目没有配重设计**，这是可以在报告"改进方案"里提的点。

### 工况总结

| 工况 | 力的关系 | 电机角色 | 实际例子 |
|------|---------|---------|---------|
| 满载上升 | 重力+摩擦都向下 | 驱动（向上出力）| 电梯上升、起重机起吊 |
| 满载下放 | 重力 > 摩擦，净力向下 | 制动（刹车）| 电梯下降、电动车下坡 |
| 空载上升 | 重力+摩擦都向下 | 驱动（向上出力）| 空电梯返顶楼 |
| 空载下放 | 摩擦 > 重力，净力向上 | 驱动（向下出力）| 少见（不经济）|

### 关键认识

上升时电机"拉东西上去"（驱动），满载下放时电机"防止东西掉太快"（制动）。这两种状态对电机要求不同，控制策略也不同 — 这是课程要求分析"回馈制动 vs 能耗制动"的根本原因。

## 五、转矩（Torque）

### 什么是转矩

转矩 = 旋转运动中的"力"。

类比：你用扳手拧螺丝。手施加的力 × 扳手长度 = 转矩。
- 力越大，拧得越紧
- 扳手越长，越省力（但转矩不变）

单位：N·m（牛顿·米）。1 N·m 大约是你用 1 牛顿的力（大约一个苹果的重量）推动 1 米长的扳手产生的扭力。

### 折算转矩

上面算的负载力是直线方向的（单位 N），但电机输出的是旋转的转矩（单位 N·m）。丝杠在中间做了转换。

折算公式：
```
T = F × L ÷ (2π × η)
```
- F = 直线方向的力 [N]
- L = 导程 [m]
- η = 传动效率（0.85 × 0.90 = 0.765）
- 2π 是因为"转一圈 = 2π 弧度"

效率 η 出现在分母，意味着：因为传动有损耗，电机实际需要输出比理论值更大的转矩。效率越低，电机越费劲。

### 三个工况的折算结果

- 空载上升：0.1554 N·m — 电机轻松
- 满载上升：0.3187 N·m — 额定工况，电机持续运行时的标准负担
- 满载下放：0.0691 N·m — 制动工况，电机需要产生反向转矩来"刹车"

## 六、转动惯量（Moment of Inertia）

### 先理解"惯量"这个概念

**直线运动中的惯性**：你推一个空购物车很容易，装满东西后同样费力推起来就很慢。
牛顿第二定律 F = m × a：m 越大，同样的力加速越慢。质量 m 是"物体有多难加速"的度量。

**旋转运动中的"惯性"**：换成旋转门，没人时容易推动，上面站三个人就很费劲。
旋转版牛顿第二定律 T = J × α：
- T = 转矩（相当于力）
- α = 角加速度（相当于加速度，单位 rad/s²）
- J = 转动惯量（相当于质量，单位 kg·m²）

**转动惯量 J 就是旋转运动中"物体有多难加速"的度量**。J 大则电机很难让负载快速加减速，J 小则响应快。

### 为什么项目要算惯量

平台从静止加速到 296 mm/s，必须在 0.6 秒内完成（题目要求）。要算加速过程需要多大的额外转矩，就必须知道整个系统有多大的转动惯量。就像算把车从 0 加速到 100km/h 需要多大力量，首先得知道车有多重。

### 整个系统的转动惯量由三部分组成

```
J_total = J_motor + J_screw + J_load
```

| 部分 | 含义 | 来源 |
|------|------|------|
| J_motor | 电机转子自身的惯量 | 电机厂家数据手册 |
| J_screw | 丝杠杆的惯量 | 丝杠参数计算或查手册 |
| J_load | 负载（平台+货物）通过丝杠折算到电机轴上的等效惯量 | 公式计算 |

三部分必须叠加：电机要同时带着自己的转子、丝杠杆、以及负载一起加速。就像你背着背包（J_motor）跑步，手里还拉着一辆推车（J_screw + J_load），腿需要克服的总惯性是三者之和。

#### J_motor（电机转子惯量）

电机里面有一根铁芯柱（转子）绕轴旋转，本身就有转动惯量。就像旋转门即使没人，门板本身也有惯性。

**不是算的，是查的。** 电机厂家在数据手册里直接给出。本项目目前为估计值 0.00001 kg·m²，待选型后替换。

#### J_screw（丝杠惯量）

丝杠是一根长金属杆（直径 16mm），跟着电机一起旋转，也有转动惯量。均匀圆柱体绕自身轴线的转动惯量公式：J = (1/2) × m × r²。本项目目前为估计值 0.000005 kg·m²，待确定丝杠型号后精确计算。

#### J_load（负载折算惯量）— 最关键的部分

负载（平台+货物）做的是直线运动，有质量（kg），没有直接的转动惯量（kg·m²）。但通过丝杠连接到电机轴上，从电机的视角看，这个直线运动的负载"等效于"多大的旋转惯量？

**折算公式**：
```
J_load = m × (L / 2π)²
```

**推导（动能等效法）**：
- 负载的直线动能：E = (1/2) × m × v²
- 等效旋转动能（从电机轴看）：E = (1/2) × J_load × ω²
- 两者相等（能量守恒，只是换了个视角）
- 丝杠运动关系：v = ω × L / (2π)
- 代入后消掉 ω²，得到 J_load = m × (L / 2π)²

注意折算公式里**没有效率 η**。因为惯量折算是运动学关系（速度、加速度的几何对应），不是能量传递关系。效率描述力的传递损耗，惯量描述物体有多"固执"不愿意改变运动状态，跟摩擦无关。

**代入数字（满载 9.5kg）**：
```
J_load = 9.5 × (0.01 / 6.283)²
       = 9.5 × 2.533 × 10⁻⁶
       ≈ 0.000024 kg·m²
```

数值很小是因为 (L/2π)² ≈ 2.53×10⁻⁶，导程越小这个系数越小，直线负载折算到电机轴上的等效惯量就越小。物理含义：导程小 = 丝杠的"减速比"大，重物折算到电机轴上就很轻，类似齿轮减速。

### 三部分合在一起

```
J_total = 0.000010 + 0.000005 + 0.000024 = 0.000039 kg·m²
```

| 部分 | 惯量 [kg·m²] | 占比 | 来源 |
|------|-------------|------|------|
| 电机 J_motor | 0.000010 | 25.6% | 查数据手册 |
| 丝杠 J_screw | 0.000005 | 12.8% | 计算或查手册 |
| 负载 J_load | 0.000024 | 61.5% | 公式折算 |
| **总计** | **0.000039** | **100%** | |

负载占 61.5%，合理。伺服设计中负载/电机惯量比应不超过 5-10 倍（惯量匹配原则），本项目比值 = 2.4 倍，非常理想。

### 惯量算出来有什么用

知道 J_total 后，就能算**加速转矩** — 从静止加速到目标速度需要的额外扭力：

```
T_accel = J_total × α
```

α = 角加速度 = 目标角速度 / 允许加速时间 = 186 rad/s ÷ 0.6s = 310 rad/s²

```
T_accel = 0.000039 × 310 = 0.0121 N·m
```

峰值转矩 = 额定转矩（克服重力+摩擦）+ 加速转矩（克服惯性）：
```
T_peak = 0.3187 + 0.0121 = 0.3308 N·m
```

加速转矩只占总额定的 3.8% — 系统几乎不需要为加速额外出力，绝大部分转矩在对抗重力和摩擦。

## 七、功率（Power）

### 什么是功率

功率 = 单位时间内做的功。对旋转运动：

```
P = T × ω = 转矩 × 角速度
```

角速度 ω 的单位是 rad/s（弧度每秒），和 rpm 的换算：ω = n × 2π / 60

### 额定功率需求：59.28 W

满载上升、快速升降时电机需要持续输出的功率。
= 0.3187 N·m × (1776 × 2π/60) rad/s ≈ 59.3 W

59.3 W 远小于 200 W 上限，说明 10mm 导程的选择留了很大余量。

### 峰值功率

启动加速时需要额外的功率来克服惯性。但因为惯量很小（0.000039 kg·m²），加速转矩只有 0.0121 N·m，峰值转矩 0.3308 N·m 只比额定多了 4%。

这意味着：这个系统主要在克服重力和摩擦，而不是在克服惯性。加速不费劲，对控制来说是好消息。

## 八、效率（Efficiency）

### 机械传动效率：0.85

题目给定。意思是从电机轴到升降平台，有 15% 的能量被导轨摩擦等损耗吃掉了。

### 丝杠效率：0.90

滚珠丝杠自身的传动效率。10% 的能量被丝杠内部的滚珠摩擦消耗。

### 总传动效率

η_total = 0.85 × 0.90 = 0.765

电机输出 1W 的机械功率，只有 0.765W 到达升降平台。剩下的 23.5% 变成了热量。

## 九、过载能力

```
电机连续功率上限: 200 W
5s 内允许 2 倍过载 → 峰值 400 W
```

电机有两个功率限制：
- **连续功率**：可以一直保持的功率，不会过热
- **峰值功率**：短时间（5秒）内可以爆发的功率，超过这个时间电机会过热烧毁

类比：你可以一直慢跑（连续），也可以短距离冲刺（峰值），但不能一直冲刺。

本项目额定功率 59.3W，峰值也就 61W 左右，远低于限制，所以功率方面完全没有压力。
